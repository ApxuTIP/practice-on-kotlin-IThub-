Зачем Kotlin

Коротко история и почему в названии курса «мультиплатформа».

02

Kotlin

Откуда взялся

2011

JetBrains начинает язык под JVM. Имя — остров Котлин под Петербургом.

2016–17

Kotlin 1.0. Google объявляет его языком Android.

Сейчас

Один язык: Android, бэкенд, частично iOS и веб. Мы берём бэкенд.

09

Kotlin

Почему не «ещё одна Java»

  • Null в типе: String? — компилятор ловит NPE до запуска.
  • Меньше бойлерплейта: data class вместо геттеров на полстраницы.
  • Живёт на той же JVM: библиотеки Java подключаются как есть.
  • Корутины — асинхронность без колбэк-ада.
10

Kotlin

Почему «мультиплатформа»

Kotlin Multiplatform — один язык, несколько целей компиляции. Общие модели и клиент. Нативный UI можно оставить платформенным.

Что делаем мы

Бэкенд на Ktor, JVM. Это тот же Kotlin. Android и iOS в этом коротком курсе не пишем — не влезем за 10 пар. Язык тот же, если пойдёте в мобилку.

Основы языка

типы, val, null, функции, class, data class, коллекции, when.

03

Основы

Типы

val age: Int = 20
val price: Double = 99.5
val ok: Boolean = true
val title: String = "Чай"

val count = 10    // тип не пишем — компилятор сам видит Int

Тип после двоеточия, с большой буквы: Int, String, Boolean. Можно не писать, если справа очевидно.

12

Основы

val и var

// один раз присвоили — больше не меняем
val pi = 3.14

// можно переприсвоить
var count = 10
count += 5

val message: String = "Hello, Kotlin"
13

Основы

Null — часть типа

val name: String = "Марк"      // null не пройдёт
val nick: String? = null        // так можно

val len = nick?.length ?: 0     // безопасный вызов + Elvis

Вопрос ? на типе. Без него компилятор не пустит null.

Основы

Функции

15

Основы

class

class Counter(var value: Int = 0) {
    fun inc() {
        value += 1
    }
}

val c = Counter()
c.inc()
println(c.value)   // 1

Обычный класс — поведение и состояние. Поля можно сразу в конструкторе: class User(val name: String).

16

Основы

Data class

data class Product(
    val id: Int,
    val name: String,
    val price: Int

val tea = Product(1, "Чай", 90)
println(tea)   // Product(id=1, name=Чай, price=90)

Частный случай class для данных. equals, hashCode, copy, toString — сами. JSON-модели — отсюда.

Hello World

Запуск

22

Запросы

curl и HTTPie

curl — консоль

Одна команда, видно статус и тело. Удобно быстро ткнуть и вставить в чат. На Windows — Git Bash или терминал IDEA.

HTTPie — рабочее место

Сохраняем запросы, заголовки, тело. История не пропадает. Дальше по курсу живём здесь: POST, JWT, файлы.

23

Запросы

Своя коллекция

  • New → Collection. Имя — как домен API. Сегодня: shop.
  • Внутри папки запросы: health, hello, products, product by id, filter.
  • Base URL: http://127.0.0.1:8080. Потом сменишь на прод, запросы останутся.
  • Коллекцию не шарим на всех: у каждого свой API и свой набор.

Задание

Сервер на :8080 отвечает так

val products = listOf(

Задание

Те же запросы в curl

curl http://127.0.0.1:8080/

27

Задание

Считается сделанным, если

  • Сервер стартует из IDEA без красного стектрейса.
  • Все пять маршрутов отвечают. 99-й товар даёт 404, не пустой 200.
  • Фильтр maxPrice реально режет список, не игнорируется.
  • Ответы JSON, не голый текст — кроме отладки на старте.
  • В HTTPie своя коллекция, все пять запросов сохраняются и проходят Send.
