# Lesson 2 — опорные материалы КТ2

Копируй куски в свой проект. Стартер: `examples/02-kt2-starter` (открыть папку в IDEA).

| Папка | Когда копировать |
|---|---|
| `01-memory/` | часть 1: POST, PUT, DELETE, класс, список |
| `02-postgres/` | часть 2: Docker, Exposed, те же маршруты в таблицу |
| `03-auth/` | часть 3: BCrypt, JWT, `/register`, `/login` |

Преза: `slides/02-ktor.html`.
